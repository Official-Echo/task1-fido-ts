# Реалізація завдання на TypeScript

Виконання Завдання 1 для FIdo: знайти вузол на позиції ⌊2n/3⌋ - 1 в однозв'язному списку.

Основна частина це бібліотека `src/index.ts` з класом `Node<T>` і функцією `getTwoThirdsNode(head)`. До неї додатково створена консольна програма у `src/main.ts`.

## Вхідні дані

Якщо не подано нічого, вхід буде прочитано з консолі.

Якщо подано одне число n, буде зроблено список довжиною n зі значеннями 0..n-1.

Якщо подано список значень `"a -> b -> c -> d"` (будь-що з розділювачем `->`), буде використано саме його. Список треба брати в лапки, бо інакше `>` сприйметься оболонкою як перенаправлення.

## Запуск

### Спосіб 1: через tgz архів та npm install

1. Завантажити архів tgz з релізів.

2. Інсталювати його в npm за допомогою команди `npm install --global node-task-1.0.0.tgz`.

3. Після цього застосунок можна вільно запускати з командного рядка, напр. `node-task 5`.

### Спосіб 2: через tgz архів та node

1. Завантажити та розпакувати архів tgz з релізів.

2. Зайти у теку `package/`.

3. Провести мінімальну інсталяцію за допомогою `npm install --omit=dev`.

4. Після цього можна довільно запускати програму за допомогою `node dist/main.js`, напр. `node dist/main.js 5`.

### Спосіб 3: через `npm start`

1. Завантажити весь репозиторій.

2. У кореневій теці провести повну інсталяцію `npm install`.

3. Після цього можна запускати програму через `npm start`, напр. `npm start -- 5`.

## Бібліотека

Архів із релізу можна встановити у власний проєкт (`npm install ./node-task-1.0.0.tgz`), пакет є ES-модулем:

```ts
import { Node, getTwoThirdsNode } from "node-task";

const head = new Node(0, new Node(1, new Node(2, new Node(3, new Node(4)))));
console.log(getTwoThirdsNode(head)?.data ?? "null"); // 2
```

## Опис

Пошук іде за один прохід, O(n) за часом і O(1) за пам'яттю. Вказівник `res` стартує з голови, `curr` біжить списком до кінця. На кожному кроці `len` росте на 1, якщо `len mod 3 ≠ 1`, `res` теж переходить на наступний вузол. Для списку коротшого за 2 елементи повертається `null`.

Тести запускаються командою `npm test`.
